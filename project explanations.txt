1. WHAT IS THIS PROJECT? (OVERVIEW)
--------------------------------------------------------------------------------
The BIAI CRM System is an AI-powered Customer Relationship Management (CRM) 
platform designed to solve a huge real-world problem for businesses in Bangladesh 
and emerging markets:

In modern businesses, prospective students and customers send inquiries from 
multiple social and web channels (WhatsApp, Facebook Messenger, Website forms, 
and Direct Phone Calls). Most of these messages are written in a mix of languages 
and scripts:
  * Pure Bangla (e.g., "ফেলোশিপ প্রোগ্রামের ফি কত?")
  * Banglish - Bangla written in English letters (e.g., "Bootcamp er details and 
    payment kibhabe korbo? call den 01711223344")
  * English (e.g., "Looking for corporate team training quotation")

Sales teams waste hours manually reading messages, copying phone numbers, sorting 
leads, drafting replies, and tracking follow-ups. Many high-value leads are lost 
because nobody responds within 48 hours.

BIAI CRM automates this entire lifecycle:
  1. It reads messages in any of the 3 languages.
  2. It automatically extracts prospect name, phone number, channel source, 
     course track, and enquiry category.
  3. It generates an instant AI response drafted in the exact same language 
     and tone as the customer.
  4. It organizes leads into an interactive 5-stage Kanban Pipeline.
  5. It flags leads that have had no response for over 48 hours (SLA breach).
  6. It isolates non-sales messages (Support, Job Seekers, Spam) to keep the 
     sales pipeline clean.
  7. It generates weekly executive AI intelligence reports with strategic advice.

2. WHAT WAS THE PROJECT BUILT WITH? (TECH STACK)
================================================================================

A. BACKEND (Python Ecosystem)
-----------------------------
* Framework    : FastAPI (High performance, async-ready Python REST API)
* Database     : SQLite with SQLAlchemy ORM (Self-contained, fast, and durable)
* Validation   : Pydantic v2 (Strict data models and input validation)
* AI Engine    : Google Gemini Generative AI (Interactions API)
* Rules Engine : Custom deterministic Python regex parser (100% resilient fallback 
                 that handles Bangla digits ০-৯, BD phone formats, and keyword matching)
* Testing      : Pytest & HTTPX (Unit, integration, and user scenario tests)
* Server       : Uvicorn ASGI Server (Running on port 8000)

B. FRONTEND (Modern Vue 3 Ecosystem)
------------------------------------
* Framework    : Vue 3 with Composition API (<script setup>)
* Build Tool   : Vite 5 (Sub-second hot-reload and lightning-fast builds)
* State Store  : Pinia (Reactive central state management with persistent theme)
* Routing      : Vue Router 4 (HTML5 history mode with single-window layouts)
* Design System: Custom Premium Dark & Light Themes (Inspired by Linear / Vercel):
                 - Deep Pitch Black (#09090b)
                 - Ash & Slate Gray cards (#121215, #18181c)
                 - Crimson Red & Electric Blue accents
                 - Dynamic tab favicons per page
                 - Single-window viewport lock with custom micro-scrollbars

C. DEVOPS & SCRIPTS
-------------------
* Startup      : `start.sh` (One-click script that sets up venv, installs npm 
                 packages, loads sample database, and starts backend and frontend)
* Shutdown     : `stop.sh` (Clean process terminator for ports 8000 and 5173)
* Repository   : Git & GitHub (https://github.com/shuvosinghpartho/BIAI_CRM_System.git)

4. KEY FEATURES & HOW THEY WORK (A TO Z)
================================================================================

1. HYBRID AI & RULES EXTRACTION ENGINE
--------------------------------------
* How it works: When a customer message is entered, the system first runs 
  fast deterministic regex rules to safely extract phone numbers and detect 
  Bangla digits.
* Then, it uses Gemini AI to understand natural language nuances (like a person's 
  name hidden inside casual Banglish text).
* Resilient Fallback: If the internet drops or AI rate limits occur, the rules 
  engine immediately takes over so the business never experiences downtime.

2. AUTOMATED LANGUAGE-MATCHED AI REPLY GENERATOR
------------------------------------------------
* The system never sends a generic reply.
* If a customer asks in Banglish:
  Input : "Bootcamp er fee koto? payment kibhabe korbo?"
  Output: "Assalamualaikum! Amader 3-day AI Bootcamp er fee 3,000 BDT..."
* If a customer asks in pure Bangla, the reply is drafted in fluent Bangla script.
* If asked in English, the reply is drafted in professional English.
* The sales agent can review or edit the reply and click "Copy Reply" with 1 click.

3. 5-STAGE KANBAN SALES PIPELINE BOARD
--------------------------------------
* Clean, interactive board with 5 standard sales stages:
  1. [New]        : Freshly received inquiries awaiting first contact.
  2. [Contacted]  : Prospect has been spoken to or messaged.
  3. [Interested] : Prospect expressed interest and requested course details/pricing.
  4. [Paid]       : Won deals! Customer completed enrollment and payment.
  5. [Lost]       : Customer dropped off, budget issue, or chose not to enroll.
* Stage Transition: Agents can change stages directly from the card dropdown 
  or inside the detail modal.

4. 48-HOUR SLA OVERDUE ALERT SYSTEM
-----------------------------------
* EdTech sales research shows that leads not contacted within 48 hours drop 
  in conversion by over 80%.
* Any sales inquiry in "New", "Contacted", or "Interested" that has not had a 
  recorded interaction for 48+ hours is automatically flagged.
* Visual Signals:
  - Pulsing radar dot indicator
  - Red glow accent strip on the card
  - "48h+ Overdue" badge
  - Dedicated "Overdue Only" filter button on the toolbar

5. 1-CLICK INSTANT CONTACT (WhatsApp & Phone)
---------------------------------------------
* Every lead card features 1-click action buttons:
  - WhatsApp Direct: Automatically formats local numbers (e.g., 01711...) into 
    the international WhatsApp format (8801711...) and opens the official WhatsApp chat.
  - Call Direct: Initiates a direct phone call via `tel:` protocol.
* Marking a lead as contacted automatically updates the `last_contacted_at` timestamp 
  and resolves the overdue alert immediately.

6. NON-SALES ENQUIRY ISOLATION (Other Enquiries View)
-----------------------------------------------------
* Not all messages are sales leads.
* Inquiries classified as "Support", "Job Seeker", or "Spam" are automatically routed 
  away from the sales pipeline to a dedicated "Other Enquiries" view.
* This keeps the sales pipeline 100% focused on revenue-generating prospects.

7. WEEKLY AI INTELLIGENCE EXECUTIVE REPORT (Summary View)
---------------------------------------------------------
* Generates an executive briefing for management containing:
  - Total inquiries and channel volume breakdown (WhatsApp, Facebook, Website, Phone)
  - SLA follow-up compliance rate
  - High-demand course track analysis
  - Strategic AI recommendations to boost sales conversions and eliminate bottlenecks
* Includes an instant "Copy Report" button for sharing in team meetings.

8. REAL HUMAN ERROR PROTECTION & IDEMPOTENCY
--------------------------------------------
* Button Spamming Defense: If an impatient user clicks "Save Lead" or "Add" 
  3-5 times rapidly, the backend idempotency guard ensures only 1 unique record 
  is created (0 duplicates).
* Form Validation: Whitespace-only messages ("   ") are rejected with friendly errors.
* Toast Deduplication: Rapid button clicks do not stack duplicate toast notifications.
* Keyboard Accessibility: Modals close instantly with the `Escape` key.

5. STEP-BY-STEP USER WORKFLOW (HOW TO USE THE APP)
================================================================================

SCENARIO: A new prospect sends a WhatsApp message.

Step 1: Open the Pipeline
  * The user opens `http://localhost:5173`.
  * The Single-Window Pipeline Board displays all active leads grouped by stage.

Step 2: Quick Add the Lead
  * The user clicks the "+ Quick Add Lead" button at the top right.
  * A modal opens. The user pastes the raw message:
    "vai bootcamp kobe start hobe? payment koto? call den 01711223344"
  * The user clicks "Auto-fill with AI".
  * In under 1 second:
    - Phone is extracted: `01711223344`
    - Program Track is set: `Bootcamp`
    - Category is set: `Sales`
    - Language is set: `Banglish`
    - A tailored Banglish response is already drafted in the preview!

Step 3: Save to CRM
  * The user clicks "Save Lead".
  * The modal closes and the new card appears at the top of the "New" column.

Step 4: Engage Prospect via WhatsApp
  * The user clicks the green WhatsApp icon on the card.
  * WhatsApp opens directly with the prospect's chat window.
  * The user pastes the AI-suggested reply and sends it.

Step 5: Move Through Pipeline
  * The user changes the card status from "New" to "Contacted".
  * Later, when the prospect agrees to enroll, the user moves it to "Interested".
  * Once the course fee is received, the user changes the status to "Paid".
  * The KPI counter at the top immediately updates to reflect the won deal!

Step 6: Review Weekly Analytics
  * At the end of the week, management clicks "Summary & Reports" in the navbar.
  * They review channel performance, overdue alerts, and read the AI Executive Report.

7. HOW TO RUN THE PROJECT LOCALLY
================================================================================

Method 1: One-Click Startup (Recommended)
-----------------------------------------
Open your terminal in the project directory and run:
    ./start.sh

This script automatically:
  1. Creates the Python virtual environment and installs backend dependencies.
  2. Installs frontend node modules.
  3. Initializes the database with the 20 real-world sample inquiries if needed.
  4. Starts the backend server on http://localhost:8000
  5. Starts the frontend app on http://localhost:5173

Method 2: Manual Startup
------------------------
Backend:
    cd backend
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

Frontend:
    cd frontend
    npm install
    npm run dev

To run automated tests:
    backend/venv/bin/pytest backend/tests -v
